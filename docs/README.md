# Landmark Properties — project documents

Everything that isn't code lives here.

| Folder | What's inside | Open it when… |
|---|---|---|
| `spec/` | `BUILD-PROMPT.md` — the full build plan, phase by phase | checking what a phase must do |
| `flowcharts/` | System 1 and System 2 flowcharts (detailed, technical) | checking exact system behaviour |
| `proposal/` | `Landmark-Feasibility-And-Costs.pdf` — tools and monthly costs | talking money with the client |

**Client presentation (simple version for the MD):**
https://claude.ai/code/artifact/e0d335f7-c532-42d2-a84b-7e1832ae2142

**Adding a new document?**
- Client-facing (proposals, quotes, decks) → `proposal/`
- Diagrams → `flowcharts/`
- Plans and requirements → `spec/`
- Anything else → make a new folder with a plain name, and add a row above.
